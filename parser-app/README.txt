NikkiNet — парсер бесплатных серверов
=====================================

Что делает
----------
Скачивает открытые публичные списки HTTP/SOCKS5-прокси и бесплатные
конфиги (vless, vmess, trojan, ss, hysteria2, tuic) из 32 источников,
убирает дубли и мусор, проверяет доступность и сохраняет рабочие
серверы в папку result\. Умеет добавлять их в NikkiNet.

Два режима сбора:
  1. Готовые списки из sources.json (GitHub-репозитории и сайты со
     списками прокси).
  2. Интернет-режим: поисковики + обход сайтов по ссылкам (seeds.txt),
     разбор HTML-таблиц, JSON, base64-блоков и share-ссылок.

Запуск
------
1. Двойной клик по run.bat
2. Выберите пункт меню (6 — глубокий сбор по интернету)

Или из командной строки:

  python parser.py --fast        собрать + быстрая TCP-проверка
  python parser.py --deep        собрать + точная проверка через sing-box
  python parser.py --internet --deep
                                 списки + поиск/обход сайтов + sing-box
  python parser.py --internet --no-search --deep
                                 только сайты из seeds.txt (без поисковиков)
  python parser.py --retest      перепроверить result\servers.json
  python parser.py --merge-only  импортировать результат в NikkiNet
  python parser.py --stats       показать статистику результата

Полезные параметры:

  --app ПАПКА        папка NikkiNet (где лежит proxy_app.py)
  --per-source 400   максимум серверов с одного источника
  --max-total 3500   общий лимит собранных серверов
  --search "запрос"  добавить свой поисковый запрос (можно несколько)
  --queries ФАЙЛ     файл с поисковыми запросами (по умолчанию queries.txt)
  --seeds ФАЙЛ       стартовые сайты для обхода (по умолчанию seeds.txt)
  --max-pages 120    сколько страниц обойти за один запуск
  --depth 2          глубина перехода по ссылкам внутри сайта
  --delay 0.7        пауза между страницами, сек
  --no-search        не обращаться к поисковикам
  --no-sources       не брать готовые списки, только интернет
  --deep-limit 500   сколько серверов проверять через sing-box
                     (0 = все, выборка случайная)
  --deep-workers 6   потоков глубокой проверки
  --cutoff 1500      максимальная задержка рабочего сервера, мс
  --merge            импортировать сразу, без вопроса
  --no-merge         не предлагать импорт
  --force            писать config.json при запущенном NikkiNet

Интернет-режим
--------------
Поисковики (DuckDuckGo, Bing) часто ограничивают автоматические запросы:
если выдача пустая, парсер продолжает работу и обходит сайты из seeds.txt.
Свои сайты можно добавить в seeds.txt, свои запросы — в queries.txt
(один адрес или запрос на строку, строки с # игнорируются).

Обход соблюдает robots.txt, заходит только на публичные страницы и
выдерживает паузу между запросами. Платные подписки и закрытые разделы
не обходятся. Внутри сайта переход идёт только по его же ссылкам.

Результаты
----------
result\servers.json   — полный список в формате NikkiNet
result\proxies.txt    — строки type://host:port
result\report.txt     — отчёт по источникам, типам и проверкам
result\web-pages.txt  — какие страницы обошёл интернет-режим

Импорт в NikkiNet
-----------------
Если NikkiNet запущен, серверы добавляются через панель
http://127.0.0.1:8000 (ничего перезапускать не нужно).
Если приложение закрыто — парсер сам дописывает config.json, предварительно
создавая резервную копию config.json.bak-ГГГГММДД-ЧЧММСС.
Если панель не отвечает, но файл .lock существует, импорт блокируется:
закройте NikkiNet или запустите с --force.

Примечание: при импорте через панель поле source у серверов становится
"manual" — так работает API NikkiNet.

Проверки
--------
--fast проверяет только TCP-порт: что хост вообще отвечает. Это быстро,
но не гарантирует, что прокси работает (HTTP-прокси должен поддерживать
CONNECT, SOCKS5 — авторизацию и т.д.).

--deep запускает настоящий sing-box из NikkiNet и делает реальный запрос
через каждый сервер. Это медленно, зато в result попадают только рабочие
узлы с задержкой не выше --cutoff. По умолчанию проверяется случайная
выборка из 500 серверов после TCP-этапа; --deep-limit 0 проверяет все.

Важно
-----
- Бесплатные публичные узлы небезопасны: владелец узла видит ваш трафик
  и может подменять содержимое сайтов. Не используйте их для банков,
  почты, работы и любых важных аккаунтов.
- Узлы быстро умирают. Запускайте парсер регулярно.
- Не публикуйте result: чужие люди получат те же узлы, и они станут
  ещё медленнее.
- Соблюдайте законы своей страны и правила источников.
- Парсер не обходит платные подписки и не ворует ключи: он берёт только
  то, что авторы сайтов и репозиториев выложили в открытый доступ.

Требования
----------
Windows, Python 3.8+, интернет.
Для глубокой проверки нужен установленный NikkiNet (используется
tools\sing-box.exe) либо папка с приложением рядом с парсером.
Путь можно указать параметром --app.
