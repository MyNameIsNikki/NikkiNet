NikkiNet Parser 1.0.0
=====================

Отдельное приложение для поиска бесплатных прокси и VPN-серверов
(vless / vmess / trojan / shadowsocks / hysteria2 / socks / http)
с графической панелью.

Запуск
------
Установленная версия: ярлык "NikkiNet Parser" на рабочем столе или в меню Пуск.
Портативная версия: start_parser.bat рядом с parser_ui.py.

Откроется отдельное окно (Edge/Chrome в режиме приложения).
Адрес панели: http://127.0.0.1:8010/
Панель доступна только с этого компьютера.

Режимы сбора
------------
1. "Списки GitHub" - быстрый сбор из 31 проверенного источника:
   списки HTTP/SOCKS-прокси и подписки с share-ссылками.

2. "Весь интернет" - дополнительно обходит публичные сайты
   (seeds.txt), вытаскивает конфиги из HTML, JSON, base64 и таблиц.
   Поисковые системы часто блокируют автоматические запросы, поэтому
   основной путь - обход сайтов из seeds.txt. Список сайтов можно
   дополнять вручную.

Настройки
---------
- "Проверять через sing-box" - настоящая проверка соединения
  (HTTP CONNECT через example.com:80). Без неё остаётся только TCP-проверка,
  которая не гарантирует работоспособность прокси.
- Источников на сайт - сколько серверов брать с одного источника.
- Всего кандидатов - лимит после объединения и удаления дублей.
- Глубокая проверка - сколько кандидатов проверять через sing-box
  (случайная выборка).
- Страниц обхода - максимум страниц в режиме "Весь интернет".
- "Добавить в NikkiNet" - после сбора отправить рабочие серверы
  в запущенную панель NikkiNet (http://127.0.0.1:8000).

Если sing-box не найден
-----------------------
Приложение ищет sing-box.exe в:
- папке приложения tools\sing-box.exe;
- ..\prox\tools\sing-box.exe;
- C:\Program Files\NikkiNet\tools\sing-box.exe.

Если файла нет, в панели появится кнопка "Скачать sing-box".
Можно также снять галочку глубокой проверки и собирать без неё.

Результаты
----------
result\servers.json - все найденные рабочие серверы (накопительно).
result\web-pages.txt - какие страницы обошёл сканер.
Кнопка "Папка результатов" открывает эту папку.

Важно
-----
Бесплатные публичные серверы небезопасны: владелец узла видит ваш трафик
и может подменять данные (MITM). Не используйте их для банков, почты,
рабочих аккаунтов. Серверы быстро умирают - запускайте сбор периодически.
Не публикуйте результаты: чужие люди получат доступ к тем же узлам.

Требования
----------
Windows 10/11 x64, Edge или Chrome, интернет.
Установщик уже содержит Python 3.12 - отдельно ставить не нужно.
