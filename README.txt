NikkiNet — УСТАНОВКА (Windows 10/11)
====================================

Способ 1 — установщик NikkiNet-Setup.exe (рекомендуется)
--------------------------------------------------------
1. Скачайте NikkiNet-Setup-*.exe со страницы релизов:
   github.com/MyNameIsNikki/NikkiNet/releases
2. Запустите его и нажмите «Да» в окне UAC.
   Python устанавливать НЕ нужно — он уже входит в установщик.
3. Готово: ярлык «NikkiNet» появится на рабочем столе
   и в меню «Пуск». Приложение запускается ярлыком.
   Установка идёт в C:\Program Files\NikkiNet.

Удаление: «Параметры → Приложения → NikkiNet → Удалить»
или «Uninstall NikkiNet» в меню «Пуск».

Способ 2 — портативный архив NikkiNet-windows-x64.zip
-----------------------------------------------------
1. Распакуйте архив ЦЕЛИКОМ в любую папку
   (правая кнопка по архиву → «Извлечь всё…»).
   НЕ запускайте файлы прямо из архива!
2. Запустите install.bat и нажмите «Да» в окне UAC.
3. Если Python не установлен — установщик сам скачает и
   поставит его (нужен интернет, ~30 МБ, 1–3 минуты).
4. Готово: на рабочем столе и в меню «Пуск» появится
   ярлык «Proxy App».

Запуск (оба способа):
   Двойной клик по ярлыку. Панель управления откроется сама:
   http://127.0.0.1:8000
   Прокси для браузера: 127.0.0.1:8888

Обновления:
   Приложение само проверяет обновления на GitHub
   (github.com/MyNameIsNikki/NikkiNet) раз в 6 часов.
   Если вышла новая версия — в панели появится
   зелёный баннер: нажмите «Обновить и перезапустить»,
   приложение всё сделает само (скачает, заменит файлы,
   перезапустится). Установщик для этого не нужен.
   Ваши серверы и настройки сохраняются.

Доступ с телефона / другого ПК:
   В панели включите «Доступ из локальной сети».
   Появится адрес вида 192.168.1.5:8889, логин и пароль.
   На телефоне (та же Wi-Fi сеть) укажите этот адрес как
   HTTP-прокси и введите логин/пароль (для SOCKS5 — тот же
   адрес с авторизацией).
   Без логина и пароля режим не включается; порт открыт
   только для локальной сети. Интерфейс 127.0.0.1:8000
   с других устройств недоступна. Чтобы закрыть доступ,
   выключите переключатель — правило брандмауэра удалится.

Автосбор серверов из интернета:
   В панели, вкладка «Серверы», блок «Автосбор серверов
   из интернета»:
   - «Собрать из списков» — проверенные GitHub-списки
     и публичные списки прокси;
   - «Собрать из интернета» — то же плюс поиск в интернете
     и обход публичных сайтов с бесплатными конфигами.
   Галочка «Проверять через sing-box» отбрасывает узлы,
   которые не пропускают трафик (проверяются HTTP и HTTPS
   с сертификатом): медленнее, но надёжнее. Неполные
   конфиги пропускаются, у одного адреса остаётся лучший
   рабочий вариант.
   Найденные серверы добавляются автоматически (источник
   autoparse), дубликаты пропускаются. Бесплатные узлы
   небезопасны: владелец узла видит трафик — не используйте
   их для банков, почты и рабочих аккаунтов.

AI-режим (ИИ через прокси):
   В панели включите «AI-режим (ИИ через прокси)».
   47 доменов ChatGPT/OpenAI, Claude, Gemini, Perplexity,
   Copilot, Midjourney и других ИИ-сервисов пойдут через
   выбранный сервер; DNS для них — через DoH и тот же прокси.
   Свои правила маршрутизации имеют приоритет.
   Нужен рабочий сервер: без него трафик пойдёт напрямую.
   Для входа в аккаунты не используйте бесплатные публичные
   прокси — владелец узла видит трафик.

Удаление (архив):
   Запустите uninstall.bat (можно из архива).

Возможные проблемы:
- SmartScreen или антивирус блокирует установщик/start.bat:
  правая кнопка по файлу → «Свойства» → галочка
  «Разблокировать» → «ОК», либо правая кнопка →
  «Запуск от имени администратора».
  Установщик не подписан цифровой подписью (подпись платная),
  поэтому SmartScreen может показать предупреждение:
  «Подробнее» → «Выполнить в любом случае».
- Антивирус удаляет tools\sing-box.exe:
  при установке оставьте галочку «Добавить папку программы
  в исключения Защитника Windows», либо добавьте папку
  установки в исключения антивируса вручную.
- «Ничего не происходит» при запуске start.bat:
  запустите start.bat из cmd — ошибка будет видна
  в окне консоли.

Требования: Windows 10/11 (x64), интернет.
