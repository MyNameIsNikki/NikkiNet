# NikkiNet

Прокси-менеджер для Windows (стиль Nekoray/HApp): локальный смешанный прокси
**127.0.0.1:8888** (HTTP + SOCKS) на движке sing-box и веб-панель управления
**127.0.0.1:8000**. Чистый Python 3.8+ без внешних зависимостей.

## Возможности

- Серверы VLESS / VMess / Trojan / Shadowsocks / WireGuard / Hysteria2 —
  вставкой ссылок `vless://…` и им подобных или вручную
- Подписки с автообновлением и отсевом неработающих серверов
- Автотест задержек, авто-выбор самого быстрого сервера (в т.ч. по стране)
- Правила маршрутизации: домены / ключевые слова / IP — через прокси или напрямую
- Системный прокси Windows одним кликом; TUN-режим (нужны права администратора)
- Cloudflare WARP одной кнопкой
- Автообновление приложения из GitHub Releases (с этой страницы)

## Установка (Windows 10/11)

1. Скачайте **NikkiNet-windows-x64.zip** из
   [последнего релиза](https://github.com/MyNameIsNikki/NikkiNet/releases/latest)
2. Распакуйте архив **целиком** в любую папку (не запускайте файлы из архива!)
3. Запустите `install.bat` и нажмите «Да» в окне UAC.
   Если Python не установлен — установщик сам скачает и поставит его.
4. На рабочем столе появится ярлык «Proxy App»; при запуске панель
   откроется автоматически: http://127.0.0.1:8000

Удаление: `uninstall.bat` (в папке установки или из архива).

## Автообновление

Приложение проверяет релизы в этом репозитории раз в 6 часов и при открытии
панели. Если найдена версия новее текущей — вверху панели появляется баннер
«Обновить и перезапустить»: приложение скачивает релиз, заменяет свои файлы
и перезапускается. **Пользовательские данные (config.json — серверы,
подписки, настройки) при обновлении не трогаются.**

## Для мейнтейнера: как выпустить релиз

Релиз собирается и публикуется автоматически при пуше git-тега:

```bash
git tag v1.1.0
git push origin v1.1.0
```

GitHub Actions скачает sing-box и wintun, соберёт `NikkiNet-windows-x64.zip`
и прикрепит его к новому Release. Чтобы установленные копии увидели
обновление, номер тега без буквы `v` должен быть больше, чем `APP_VERSION`
в `version.py` (сравнение числовое: `1.10.0` > `1.2.0`).

## Состав

| Файл | Назначение |
|---|---|
| `proxy_app.py` | ядро: состояние, логика, HTTP-API панели |
| `singbox.py` | генерация конфигов и управление sing-box |
| `subs.py` | парсер ссылок и подписок |
| `warp.py` | регистрация Cloudflare WARP |
| `ui.py` | веб-панель (один HTML-файл) |
| `version.py` | версия приложения + репозиторий обновлений |
| `appupdate.py` | проверка релизов и самообновление |
| `install.bat` / `start.bat` / `uninstall.bat` | установка / запуск / удаление |
